# BT Chat — Bluetooth-чат между двумя телефонами

Простое Android-приложение: офлайн-чат 1-на-1 через классический Bluetooth
(RFCOMM), без интернета и без SMS. Работает только между двумя телефонами,
на которых установлено это же приложение.

## Как собрать APK

1. Установите **Android Studio** (последнюю стабильную версию) —
   https://developer.android.com/studio
2. Откройте Android Studio → **File → Open** → выберите папку `BtChat`
   (эту самую, где лежит файл `settings.gradle.kts`).
3. Android Studio заметит, что в проекте нет файлов Gradle Wrapper
   (`gradlew`, `gradlew.bat`, `gradle/wrapper/...`), и сама предложит их
   создать — нажмите **"Yes" / "OK"** на всплывающем предложении.
   Если предложения не было, сделайте это вручную:
   **Tools → Gradle → Generate Gradle Wrapper**.
   Wrapper создаётся за секунды, так как у Android Studio есть доступ в
   интернет (в отличие от среды, где этот код был написан).
4. Дождитесь окончания **Gradle Sync** (полоска внизу окна).
5. Подключите телефон по USB с включённой **USB-отладкой**
   (Настройки → О телефоне → 7 раз тапнуть "Номер сборки" → Настройки
   разработчика → USB-отладка), либо сразу соберите APK без телефона:
   **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
6. Готовый файл появится в
   `app/build/outputs/apk/debug/app-debug.apk` — можно скопировать на
   телефон и установить (разрешите установку из неизвестных источников).

Либо просто нажмите зелёную кнопку **Run ▶** — Studio соберёт и поставит
приложение прямо на подключённый телефон.

## Как пользоваться

Нужно два телефона с установленным приложением.

1. На **обоих** телефонах включите Bluetooth и разрешите приложению
   запрошенные разрешения (при первом запуске).
2. Один телефон (назовём его "Б") нажимает **"Ждать подключения (как
   сервер)"** — он переходит в режим ожидания.
3. Второй телефон ("А") нажимает **"Искать устройства рядом"**. Если
   телефоны раньше не были сопряжены по Bluetooth — сначала выполните
   обычное сопряжение в системных настройках Bluetooth Android (Настройки
   → Bluetooth → найти устройство → "Сопряжение"), затем список
   сопряжённых устройств появится в приложении.
4. На телефоне "А" нажмите на имя телефона "Б" в списке — начнётся
   подключение.
5. Когда соединение установлено, у обоих открывается экран чата —
   переписывайтесь, сообщения идут напрямую по Bluetooth, без интернета.

## Структура проекта

- `BluetoothChatService.kt` — вся логика Bluetooth: сервер (приём
  соединения), клиент (подключение к выбранному устройству), поток чтения
  и записи сообщений через RFCOMM-сокет.
- `MainActivity.kt` — стартовый экран: проверка/включение Bluetooth,
  запрос разрешений, поиск устройств и список сопряжённых.
- `ChatActivity.kt` — экран переписки.
- `DeviceListAdapter.kt` — список найденных/сопряжённых устройств.

## Важно про разрешения (Android 12+)

Начиная с Android 12 система ввела отдельные разрешения
`BLUETOOTH_SCAN` / `BLUETOOTH_CONNECT` / `BLUETOOTH_ADVERTISE` вместо
старого `ACCESS_FINE_LOCATION` для поиска устройств. Манифест и код в
проекте уже учитывают оба случая — для Android 6–11 и для Android 12+.
